## Phase B — the fourth surface: model, fingerprint shape, defaults-layer kind, schema-1 cut

This is the central modelling phase. Item 4 of the substance is the question; the recommendation below is a starting point to be **measured** against `compute_fingerprint`, `_check_open_node_addressing`, `_check_the_migrated_document_is_accepted`, and `read_defaults_document`, and overturned if any of them says no.

**The document shape.** A backend file is `[defaults]` + one root table per model name (+ header-shaped keys inside a model table). Neither `[defaults]` nor a model table is an `InferenceModelSpecBlueprint` on its own — only their merge is (`sdk` is required and normally lives in `[defaults]`). So the fingerprint must record the *file-node* shape: every root table is an all-optional partial spec, and the root itself is an open node.

- [ ] **The partial projection.** Recommendation: a mechanically-derived all-optional projection of `InferenceModelSpecBlueprint` (every field `X | None = None`, `extra="forbid"` irrelevant to the fingerprint since extras are invisible to it), produced by one function in the migration package (or beside the blueprint) so there is **one** field list — with a test pinning `set(projection.model_fields) == set(InferenceModelSpecBlueprint.model_fields)` so the two can never drift. Alternative if dynamic model creation reads badly under the python standards: an explicit hand-written `InferenceModelSpecFileNode` model beside the blueprint with the same drift test. Either way it is a **projection for the fingerprint and the transform check only** — the loader keeps validating the merge against the real blueprint; nothing about how a backend file boots changes here.
- [ ] **The open root.** `compute_fingerprint` seeds `prefix=()` from `config_model.model_fields`, so a `dict[str, Partial]` has to be a *field* to be recorded as an open node — which puts a phantom parent in every path (`models.*.sdk`) that no TOML document has, and a `RootModel` does the same with `root.`. Recommendation: give the surface a way to say *the document root is itself an open node whose value schema is `config_model`* — the smallest honest extension is a `Surface.document_root_is_open: bool` (name to taste) that `fingerprint_at` turns into a seed at path `("*",)` (one root open-node record with `open_node=True` and no parent, then the projection's fields beneath `*`), so the fingerprint records `*` and `*.sdk`, `*.enabled`, `*.model_type`, … and `[defaults]` is simply one of the `*` keys. Then `delete_key` with `table_path=["*"]`, `key="prompting_target"` addresses `*.prompting_target`, which is exactly the material the entry declares. **Measure `_check_open_node_addressing` against a root `*` before committing to this** — if it requires a recorded parent for the `*` segment, teach it that the root may be the open node (red-first test in `test_ledger_check.py`) rather than inventing a parent. Record the shape as built in Status and in `docs/migration-ledger.md` § The fingerprint.
- [ ] **The third `DefaultsLayerKind`** (D3). Recommendation, name to be ruled at CP1: `OPTIONAL_DOCUMENT` (*"the file is copied, not layered; every key of the document is optional at the document level and the model supplies the value, so an added field is absorbed by construction"*). What it means for the four readers of the kind:
  - `read_defaults_document()` → `{}`: there is no defaults document, and the defaults-layer rule (`coverage.check_defaults_layer` — every *required* path has a default) holds vacuously because the projection has no required path. Say so in the docstring; do not fake a document.
  - `render_reference_document()` → the **representative kit file**, e.g. the kit's `openai.toml`, named on the surface as `reference_document_path` (a new field, not a reuse of `packaged_document_path`, whose name means "merged beneath the user's file", which this is not). This is what `umig` snapshots as `defaults@N.toml`, so a *later, non-pre-history* entry has a real starting document to be replayed over (`transform_check._read_document_the_entry_migrates_from`), and `coverage._check_head_defaults_document` keeps its byte-compare. It is the substance's item 5 answered before a second entry arrives. Alternative considered and rejected: no `defaults@N.toml` for this kind — it works for a pre-history first entry (the head has no `after` and `_check_link` returns `[]`) and breaks the second entry.
  - `reference_documents()` → the reference document **plus every `*.toml` in the kit's backend directory** as convergence/neutrality witnesses (`kit_template_path: Path | None` generalises to `kit_template_paths`, or a `kit_template_dir` + glob — pick the smaller change; the three existing surfaces keep one path). More witnesses than any other surface has, at no cost, and it is exactly the set `pipelex init` copies. `_check_convergence` is the only reader (`ledger_check.py:595`).
  - the `check_defaults_layer_is_reachable` validator: extend the "packaged path ⇔ PACKAGED_DOCUMENT" pairing to "reference document path ⇔ OPTIONAL_DOCUMENT" and keep both mutually exclusive.
  - **`transform_check._check_the_migrated_document_is_accepted`** (head only) validates the migrated document against `config_model` — for an open-root document that means validating *each root table* against the projection (and, since the loader merges `[defaults]` into each model table, the honest acceptance check for this surface is *the merge of `[defaults]` and each model table validates against the real blueprint* — decide which, write it as a `Surface.validate_document(...)` seam the check calls, and say in its docstring which of the two it proves). Red-first test.

## Known traps and open risks (read before each phase)

- **The pre-history checks skip the walk** (`coverage.py:143-146`, `ledger_check.py:157-163`) — that is why a `move_key` onto a destination the frozen previous fingerprint already has does not trip `DESTINATION_OCCUPIED`, and why every op is instead checked against `declared_removed_paths` at its **literal, pre-entry path** (`_check_pre_history_source_is_declared_material`, no rename chaining). Declare every path an op addresses.
- **`PRE_HISTORY_HAS_A_DIFF`** fires if the fingerprint pair around a pre-history entry shows any removal or narrowing. For `pipelex-config@2` the pair is (`@1`, a copy of `@1`) — trivially no diff. For `inference-backend@2` it is (`@1`, `@2`) both cut on today's projection — same. If either fires, the goldens were not what the plan says; do not `umigf` your way past it.
- **`umig` rewrites the head only and refuses a destructive overwrite**; after the renumber the head `@3` must come out byte-identical to the moved `@2` files, and after the backend cut `@2` must equal `@1` but for the version label. Any other diff is a finding.
- **`replay_surface_files_in_memory` deep-merges its paths** — one path per call for backend files.
- **`_is_within` resolves the parent, never the file** — keep the S7 asymmetry when it learns about subdirectories (a symlinked backend file out to a dotfiles repo is in reach).
- **`backends_dir_path` is resolved per directory, project wins the whole directory** — the walk repairs both roots; the loader loads one. Not a bug; a sentence in a docstring.
- **`extra="allow"` keys are invisible to the fingerprint**, a `RootModel` projects a phantom `root.`, and `compute_fingerprint` seeds `prefix=()` — the open-root seed is the smallest change that makes the paths honest; measure before building.
- **`InferenceModelSpecBlueprint.sdk` is required** — a `MODEL_DEFAULTS` surface on it raises `MigrationRegistryError` at registry build (`surfaces.py:149-163`); the projection is what makes the surface buildable.
- **Two `.md` files live in the backend directory** (`pipelex_gateway_models*.md`) and `pipelex_inference.toml` (not kit-shipped) is beside them on this laptop — the glob `*.toml` and the (directory, name) rule handle both; the tests must include both shapes.
- **`config_surface.py` may not import `surfaces.py`** (kernel-layer closure; `check-hub-layering` chases `interpreter_hub` only, so only the full `agent-test` would see it — see the memory note). Read the subdirectory from the ledger, not the registry.
- **`.claude/skills/add-migration` says never hand-edit a golden** — copying `fingerprint@1 → @2` and `git mv @2 → @3` is the one sanctioned exception, and its proof is that `umig` is a no-op afterwards; write that into the skill (Phase E) so the next person is not left to argue it.
- **No hardcoded counts** in the docs you touch — "the four surfaces" is the same trap "the three surfaces" was; write "every surface" where the number is not the point.
