    Error Reference

    Every Pipelex error class has a stable RFC 7807 type URI on the form <base_uri>/<kebab-class-name>/, and that URI dereferences to one of the pages below. The list is grouped by the top-level branch a class belongs to so the structural shape of the hierarchy stays visible.

    See Error Model for the underlying contract, classification rules, and the cross-boundary Temporal bridge.
