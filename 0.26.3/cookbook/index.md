# Pipelex Cookbook Examples

Welcome to the Pipelex Cookbook!

[![GitHub](https://img.shields.io/badge/Cookbook_Repository-5a0dad?logo=github&logoColor=white&style=flat)](https://github.com/Pipelex/pipelex-cookbook/tree/main)

This is your go-to resource for practical examples and ready-to-use recipes to build powerful and reliable AI methods with Pipelex. Whether you're a beginner looking to get started or an experienced user searching for advanced patterns, you'll find something useful here.

We strongly encourage you to clone the [Pipelex Cookbook repository](https://github.com/Pipelex/pipelex-cookbook/tree/main), play with the examples, and tailor them to your specific needs.

## Quick Start

- [**Hello World**](./hello-world.md) — The simplest Pipelex pipeline: a single LLM call that generates a haiku.
- [**Summarize**](./summarize.md) — Multi-step text summarization with topic extraction and batching.

- [**Generic Document**](./extract-generic.md) — Extract markdown from complex PDFs using vision.

- [**Proof of Purchase**](./extract-proof-of-purchase.md) — Extract receipt data including product lists.
- [**DPE (Energy Diagnostic)**](./extract-dpe.md) — Specialized extraction for French energy performance certificates.

- [**Markdown from Document**](./extract-markdown.md) — Simple document-to-markdown using shared method packages.
- [**Slides from Presentation**](./extract-slides.md) — Extract slide content and descriptions with vision analysis.
