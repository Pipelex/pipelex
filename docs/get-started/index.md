# Getting Started

There are two ways to build methods with Pipelex:

- **[Build with Claude Code](build-with-claude-code.md)** (Recommended) — describe what you want in natural language, and Claude writes, runs, and iterates on your method for you.

- **[The MTHDS Language Tutorial](mthds-language-tutorial.md)** — learn the declarative MTHDS language step by step: pipes, sequences, inputs, and structured outputs.
