# `wip/history/`

This folder holds shipped project records, old audits, and point-in-time recaps that are useful for archaeology but should not compete with active `wip/` priorities.

The active priority view is [`../executive.md`](../executive.md). If a historical doc still contains a real pickup item, surface that item in `executive.md` instead of moving the whole record back to the active tree.

## Contents

- [`archive/`](archive/) - former `wip/archive/` records.
- [`csv-support/`](csv-support/) - shipped CSV input/output feature notes and deferred expansion items.
- [`keyword-only-arguments/`](keyword-only-arguments/) - completed keyword-only refactor, audits, and downstream notes.
- [`registry/`](registry/) - shipped cost-reporting/usage-registry work and remaining deferred design decisions.
- [`signature-based-validation/`](signature-based-validation/) - completed signature validation feature record.
- [`tests/`](tests/) - completed test-grind notes.
- [`recursivity/`](recursivity/) - completed additive multi-file/recursive-design handoffs.
- Top-level HTML files - rendered PR or design recaps kept as static snapshots.
