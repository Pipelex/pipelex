# Hub layering — working docs

Working notes for the `refactor/Hub` track: splitting `pipelex.hub` into two hubs and drawing an enforced layering boundary between them. **Track complete** — the repo-root `TODOS.md` tracker was archived here on 2026-07-27 once `_hub/` moved on to the `refactor/Modularity-3` track. What is left is not a phase, it is the release-gated cross-repo sweep (see the tracker's [Cross-repo sweep](hub-split-tracker.md#cross-repo-sweep) section).
